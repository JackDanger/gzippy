macOS embeds a random LC_UUID per link, so per-build binary shas are NOT
reproducible even for identical code — BASE/SKIP vs BASE2/SKIP2 differ by
UUID only (same size 1,744,112 B). The identity tests that MATTER are
output-stream shas: BASE2 and SKIP2 both emit `bcabfc5f…` at in16m L12 -p4,
exactly the battery's recorded stream pair. The wall battery ran against
BASE2/SKIP2; the byte battery ran against BASE/SKIP.

BASE and SKIP are byte-identical in SIZE (1,744,112 B): with both new features
off, the instrument and the break compile to nothing. CNTR/SKIPC carry the
instrument (1,793,648 B — +49,536 B of counter table and call sites).

### 3.4 The subagent review capacity (the user-mandated mechanism)

No native spawn tool in this harness. Built it from the CLIs on this machine:

* **How**: write a scope-specific adversarial brief to a file (frame the
  1-byte difference, the exposing input, the failing test), launch
  `claude -p "$(...)" --model claude-sonnet-4-5 > out.md 2>err &` and
  `timeout 780 codex exec --sandbox read-only -C /repo - < prompt.md > out 2>&1 &`
  (via stdin, NOT argument — one early invocation was OOM-killed at argv
  limits), read both outputs, fix real findings, put verdicts in the PR thread.
  Run both in parallel; the two vendors did not share one blind spot yet.
* Files used this session (ephemeral `/tmp`, contents summarized into the PR
  bodies — use the PRs, not these paths): `/tmp/review_claude.md`,
  `/tmp/review_codex.md`, `/tmp/s2review_claude.md`, `/tmp/s2review_codex.md`.
